## Publishing

This repo is static and has no build step.

1. Create a GitHub repository named `abelisauridae.github.io` under the
   `abelisauridae` account.
2. Push these files to the repository's default branch.
3. In GitHub Pages settings, serve the site from the repository root if it is
   not enabled automatically.

The homepage will appear at `https://abelisauridae.github.io/`.
